# Workflows

Eight focused procedures, written as project skills in `.claude/skills/` (readable as plain Markdown):

| Skill | Use it to |
|---|---|
| `td-scientific-ui` | add or review controls, states and charts |
| `td-npg-bringup` | connect the board, debug packets and counters |
| `td-acquisition-quality` | diagnose noisy or inconclusive sessions |
| `td-dsp-checks` | change or verify signal processing |
| `td-protocol-design` | design protocols and read results descriptively |
| `td-session-reports` | write reports and public case studies |
| `td-illustration-adaptation` | turn video motion graphics into web illustrations |
| `td-release-gates` | prepare a clean public release |
